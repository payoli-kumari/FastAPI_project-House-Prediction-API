How it works

1

You enter property details

Income level, house age, room count, location coordinates, and occupancy info for the block.

2

The ML model runs

A RandomForestRegressor with 100 decision trees processes your input and returns a price prediction instantly via REST API.

3

You get an estimate

The predicted price is shown with a confidence range of ±$38K based on the model's mean absolute error on test data.
